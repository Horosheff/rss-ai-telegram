# Документация: Cursor Cloud Agents

Источник: [cursor.com/docs/cloud-agent](https://cursor.com/docs/cloud-agent).

## Что это

- **Cloud Agents** — те же агенты Cursor, но в **изолированном облаке** (не на вашем ПК).
- Плюсы: **много параллельных запусков**, **не требуют**, чтобы локальная машина была онлайн; на ВМ можно **собирать, тестировать**, использовать **удалённый рабочий стол и браузер**; доступны **MCP** (БД, API, сервисы).

## Как запускать

| Канал | Действие |
|--------|----------|
| Web | [cursor.com/agents](https://cursor.com/agents) |
| Desktop | В выпадающем списке под полем агента выбрать **Cloud** |
| Slack / GitHub / Linear | Команда **@cursor** (PR/issue и т.д.) |
| API | Программный запуск агента |

PWA: Safari/Chrome — «Добавить на главный экран» для удобного мобильного доступа к веб-агентам.

## Работа с кодом (GitHub / GitLab)

- Клонируют репозиторий, работают в **отдельной ветке**, **пушат** изменения для передачи работы.
- Нужны **права read-write** на репо и зависимые репо/субмодули.
- Другие провайдеры (например Bitbucket) — **позже**.

## Модели

- Используется **подборка моделей** всегда в **[Max Mode](https://cursor.com/docs/models-and-pricing#max-mode)**; **выключить Max Mode для Cloud Agents нельзя**.

## MCP

- MCP настраиваются для команды через **выпадающий список MCP** на [cursor.com/agents](https://cursor.com/agents).
- Поддерживаются **HTTP и stdio**, **OAuth** при необходимости. Детали: [Cloud Agent capabilities](https://cursor.com/docs/cloud-agent/capabilities).

## Hooks

- Выполняются **проектные** хуки из [`.cursor/hooks.json`](https://cursor.com/docs/hooks).
- На **Enterprise** — также team/enterprise-managed хуки (форматтеры, аудит, политики в облаке).

## Артефакты и удалённый стол

- **PR с артефактами**: скриншоты, видео, логи для проверки изменений.
- **Удалённый desktop**: можно вручную потестировать сборку, затем вернуть управление агенту.

## Биллинг

- Списание по **API-ценам выбранной модели**; при первом использовании просят задать **лимит расходов**.

## Типичные проблемы (из доков)

- **Агент не стартует**: логин, подключённый **GitHub/GitLab**, права на репо, **платный план** Cursor.
- **Секреты недоступны**: добавить в [Dashboard → Cloud Agents → secrets](https://cursor.com/dashboard/cloud-agents), учесть scope workspace/team, при необходимости **перезапустить** агента.
- **Snapshots / `.env.local`**: снимки окружения могут включать `.env.local`, если вы их включили при создании; **рекомендуется** секреты через UI, не копировать чувствительное в снапшоты необдуманно.
- **Slack**: проверить установку приложения и права админа workspace.
